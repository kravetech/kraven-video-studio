# Public release — 1.0.0

**Kraven Video Studio — You shoot. AI edits. You approve.**

Version **1.0.0** begins this repository with a reviewed snapshot of the existing stable implementation. It includes portrait/landscape workflows, editorial gates, managed render storage, configurable safe cleanup, pinned Zod 4.6.6 and bounded Windows atomic-file retries. Original application code and dependency/tool pins are retained; source history and release documentation are newly established.

Obtain the source-installer ZIP and its checksum from the matching release. Verify the full source commit and manifest before execution. Earlier installations may have reused the version number or have a higher number: source identity, not number ordering alone, distinguishes this baseline.

Install into a fresh folder. Preserve any existing application, media and approval evidence. Migrate private preferences only by deliberate choice; fresh installation does not import them automatically. Publication does not switch a production installation.

Original project code is Apache-2.0. Downloaded runtimes, models, fonts, dependencies and services retain their own terms. Tools, models, dependencies, local settings, credentials, private records, media and Git history are excluded from the source-installer ZIP.
